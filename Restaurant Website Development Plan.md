# Restaurant Website Development Plan

## Project Overview
Create a sophisticated, single-page HTML/CSS/JS website for an intimate 10-person apartment restaurant in Budapest's District VII (Rumbach Sebestyén utca), hosted on GitHub Pages.

---

## Design Direction: Refined Minimalism with European Elegance

### Aesthetic Choices

**Tone**: Luxury/refined minimalism with a touch of local character

**Typography**:
- Display: "Playfair Display" (elegant serif for headings)
- Body: "Lora" (sophisticated serif for content)

**Color Palette**:
- Deep charcoal (#1a1a1a) for text
- Cream/off-white (#faf9f6) for background
- Warm gold/brass accents (#c9a961)
- Soft gray (#e8e7e4) for subtle divisions

**Differentiator**: Location-specific touch—subtle reference to Budapest's thermal culture and European elegance; smooth scroll animations; intimate scale messaging

---

## Development Plan

### Phase 1: Setup (5 minutes)
1. Create local project directory
2. Initialize git repository
3. Create basic folder structure

### Phase 2: HTML Structure (10 minutes)
Build semantic HTML with sections:
- **Navigation**: Sticky header with restaurant name
- **Hero Section**: Dramatic introduction with location emphasis
- **About Section**: Intimate dining concept, chef's philosophy
- **Menu Preview**: Highlights (expandable on hover/click)
- **Reservation CTA**: Simple contact form or booking link
- **Details Section**: Address, hours, capacity info
- **Footer**: Social links, copyright

### Phase 3: Styling (15 minutes)
- CSS variables for theming
- Elegant typography scaling
- Responsive layout (mobile-first)
- Subtle animations (fade-in on scroll, hover effects)
- Location-aware styling (warm, inviting, intimate)

### Phase 4: Interactivity (10 minutes)
- Smooth scroll navigation
- Menu toggle/expansion
- Contact form validation
- Scroll-triggered animations
- Mobile menu toggle

---

## Tech Stack
- **HTML5**: Semantic structure
- **CSS3**: Modern layout (Flexbox/Grid), CSS animations, variables
- **Vanilla JavaScript**: No frameworks needed for elegance
- **Fonts**: Google Fonts (Playfair Display + Lora)
- **Hosting**: GitHub Pages (free, simple, perfect for static sites)
